# csv-analyzer-app
A lightweight, user-friendly web application built with Streamlit to analyze CSV files quickly and efficiently. This tool allows users to upload multiple CSV files, automatically process the first column of each file, and generate insights such as total and unique value counts.

🚀 Features

📁 Upload multiple CSV files at once
⚡ Automatic processing of first column
📊 Metrics calculated:

Total number of values
Number of unique values


🔄 View modes:

Total Count
Unique Count
Both


📋 Interactive results table
📈 Progress indicator for large batch processing
⬇️ Export results:

CSV format
Excel (.xlsx)


⚠️ Robust error handling:

Empty files
Corrupted CSVs
Missing data
